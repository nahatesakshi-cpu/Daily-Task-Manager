# Daily Task Manager

A modern and responsive Daily Task Manager web application built using HTML, CSS, and JavaScript.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- All, Active, and Completed filters
- Task priority management
- Due dates and deadlines
- Task categories
- Search functionality
- Subtask management
- Drag and drop task sorting
- Dark and Light mode
- Productivity dashboard
- Task statistics and charts
- Browser notifications
- Local Storage for saving tasks
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage
- Chart.js

## Color Theme

Lavender, Purple, Peach, and Cream.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Start managing your daily tasks!
